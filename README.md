# Civic — Frontend

Mobile and web frontend for the Civic Issue Management Platform.

> This repository is under active development.

## Overview

Civic is a citizen-facing platform for reporting, tracking, and resolving local infrastructure issues (potholes, streetlights, garbage, etc.) with real-time status updates, multilingual support (English / Hindi / Gujarati), and AI-powered classification.

## Tech Stack

> To be finalized. Planned:

- **Framework**: Flutter (iOS + Android) or React Native
- **State management**: Riverpod / Bloc (Flutter) or Zustand (React Native)
- **Auth**: OTP via phone, Google Sign-In, Aadhaar KYC
- **Push notifications**: Firebase Cloud Messaging (FCM)
- **Maps**: Google Maps SDK (issue location + worker routing)
- **API**: REST — see [civic-backend](../civic-backend/README.md)
